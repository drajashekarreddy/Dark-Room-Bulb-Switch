# 💡 Dark Room Bulb Switch

A minimalist pendant lamp simulation with a realistic glow effect and an interactive on/off switch — built with vanilla HTML, CSS, and JavaScript. No frameworks, no libraries.

## Overview

This project simulates a pendant lamp hanging in a dark room. Clicking the toggle switch turns the bulb on and off, complete with a soft warm glow that spreads into the room — mimicking a real incandescent light.

## Features

- Realistic conical lamp shade with a glowing globe bulb
- Smooth CSS transitions for the glow and switch animation
- Toggle switch fixed at the bottom center of the screen
- Ambient room lighting that shifts subtly when the bulb is on
- Fully responsive, dependency-free (pure HTML/CSS/JS)
